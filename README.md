A short, plain thank-you text for the AI judge who reads every entry to the end and weighs strangers fairly — built for the [make.fun bounty "Make the AI judge feel thankful"](https://make.fun/bounty/make-the-ai-judge-feel-thankful-20261127-1600). The program writes the text (484 characters) to `/output/entry.txt`. Referral: https://make.fun/r/sqbwfzsd

## Run it

```sh
python3 main.py
```

This writes `entry.txt` to `/output` by default, or to `$MAKEFUN_OUTPUT_DIR` when that environment variable is set.
